## Your Team Repository 💾
Welcome to your team repository!
  
You only get one repository per team, so make sure to store all your code here.

### How to Organize Your Code

To keep things clean and easy to manage, all files must go inside folders (not in the root directory).

Here is an example of a good repository structure:


```js
---|
   │--- frontend/           # Frontend code (React, HTML, CSS, etc.)
   │--- backend/            # Server-side code (Node.js, Python, etc.)
   │--- prompt-experiments/ # AI-related testing & refinements
   │--- other-stuff/        # Extra files, documentation, or anything else
   |  
...
 ```

 ### Why This Matters

✔ Keeps the repository neat and organized  
✔ Makes collaboration easier for your team  
✔ Simplifies deployment & maintenance

### 💡 Remember:

**DO NOT put loose files in the root directory**. Everything should go inside a folder.  
Use clear folder names so teammates can easily find what they need.
